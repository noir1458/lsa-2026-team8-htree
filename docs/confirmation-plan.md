# 추가 확인 계획

1차 자료를 모두 수집한 뒤, 추가 측정 전에 기록했다(2026-11-18).

1차 측정에서 100·1,000개 디렉터리의 변동이 컸다. HTree를 사용하지 않는 100개 조건과 dentry 예열 조건에서도 정책 라벨별 시간 차이가 있었다. 1,000개 노드(count=8)에서 hybrid8과 hybrid16은 같은 선형 탐색을 하지만 측정값이 달랐다. 이 차이를 정책의 성능 효과로 해석하지 않는다.

다른 부팅 세션에서 동일한 이진 탐색을 두 라벨(binary, binary_shadow)로 실행해 측정 변동을 확인한다. 비교 대상은 binary, binary_shadow, linear, hybrid8이다. 1,000개와 100,000개 디렉터리에서 warmdir 조건만 20회씩 반복하고 새 seed 20261119를 쓴다. 코드·이미지·캐시 준비 방법은 1차와 같으며, binary_shadow는 스크립트에서 정책 0을 설정하는 이름만 다른 대조군이다.

기존 자료는 버리거나 대체하지 않는다. 추가 결과를 별도 confirm-n* 디렉터리에 남긴다. 작은 차이가 다시 나타나더라도 동일 정책 대조의 변동과 함께 해석한다. 1차에서 관측한 큰 디렉터리의 선형 탐색 손해가 재현되는지도 확인한다.
